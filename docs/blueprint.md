# **App Name**: EduPro

## Core Features:

- Resume Parsing Interface: Interactive resume upload and parsing: accept DOC/PDF, render uploaded file and its contents, show a loading animation during parsing, show any parsing errors clearly to the user.
- AI Role Matching: Trending Role Matcher tool: Matches the parsed resume content against a list of trending job roles, showing skills matched, skills missing, and suggesting an AI-generated course bundle of skills to address these gaps.
- Skill Gap Display: Skill gap visualizer: Display progress bar and a simple skill radar chart showing user skills vs required skills for their desired roles.
- Landing Page: Landing page includes sections with key features (icons and cards), testimonials carousel and 'Get Started' CTA button.
- Static Content Pages: Clear, concise 'About' and 'Contact' sections. Prominent website name in top navigation bar.
- Course bundle UI: Dynamic course bundle results display showing title, thumbnail, and a brief description.

## Style Guidelines:

- Primary color: Deep purple (#673AB7), for intellectualism and creativity
- Background color: Very light purple (#F3E5F5).
- Accent color: Blue (#3F51B5), analogous to the primary purple, used for buttons and highlights, with enough difference in saturation to create good contrast.
- Headline font: 'Space Grotesk', a sans-serif for headlines. Body font: 'Inter', a sans-serif for body text.
- Use modern, line-based icons to represent key features and skills.
- Clean and structured layout with clear sections for resume upload, skill matching results, and course suggestions.
- Subtle transitions and loading animations for a smooth user experience.
